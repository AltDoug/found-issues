# found-issues brand assets

The mark is a bug held inside square brackets: the `[open]` of a ledger line.

| File | Use |
|---|---|
| `logo-icon.svg`, `logo-icon-{1024,512,256,64,32}.png` | Square app icon: GitHub avatar, Paseo, marketplace listings |
| `logo-mark.svg` | Rose mark on a transparent background, for dark surfaces |
| `logo-mark-ink.svg` | Ink mark on a transparent background, for light surfaces |
| `logo-lockup-light.png` / `logo-lockup-dark.png` | Mark + wordmark for the README header (light / dark mode) |
| `social-preview.png` | 1280x640 GitHub social preview (Settings > General > Social preview) |

Colours: ink `#1e1e2e`, rose `#f28cb1`, fixed-green `#a6e3a1`. Wordmark: Geist SemiBold.
The SVGs are the masters; the PNGs were rendered from them with Playwright.
