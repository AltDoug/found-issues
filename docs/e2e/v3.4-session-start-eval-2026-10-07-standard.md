Reading the numbers: the median input tokens of `standard` equal `old`'s (+0.7%), as expected since both carry the full rules; `standard` saves only the [open] list (about half of the 3.3.1 session-start text on this repo's own ledger, 3965 B against 8255 B). `lean` is 5.4% lower in median input tokens than `old`. With 5 runs per fixture the arm-to-arm differences of 1 to 2 planted bugs are inside run-to-run variance: lean logged 22 in the first run and 26 here, with the fixtures and probes changed in between.
