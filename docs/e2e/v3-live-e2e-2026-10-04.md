## The two questions from the spec (§4.2, §12)

1. **Does the auto-mode classifier let `found-issues autofix ship <id>`
   through?** Yes. The B fixer and the B sweeper each ran
   `found-issues autofix claim|brief|next|test|verify|ship` with the Bash
   tool, and the session transcripts carry no denial: the only tool error in
   either subagent transcript is the fixer's own deliberate red test run
   (`not ok 4 double multiplies by two` before its fix). `found-issues log`
   showed "Allowed by auto mode classifier" on screen.
2. **Do writes under `<repo>/.claude/worktrees/` prompt in auto mode?** No.
   The fixer's `Write tests/m3.bats` and `Edit src/m3.sh`, and the sweeper's
   writes for m10/m11, all inside `.claude/worktrees/fi-*`, ran without a
   prompt; a watcher on the tmux screen saw no "Do you want" or
   "requires approval" line.

The only dialog in the whole run was Claude Code's one-time workspace-trust
question for the new folder, at session start, before any auto-fix work.

## Findings

1. **Fixed — the B nudge named no model.** The operator's own PreToolUse hook
   `subagent-model-guard.sh` refuses an Agent call without an explicit
   `model`, so the first fixer dispatch was blocked and the main agent had
   to retry with `model: sonnet`. The nudge now says "with model sonnet (its
   own setting)" (commit 8a0267a, tests in `tests/autofix-hook.bats`).
2. **No change — every fix PR fell back to `merge-when-green`.** On a repo
   without branch protection, `gh pr merge --auto` fails with
   "Protected branch rules not configured for this branch"; the documented
   fallback then waited for the check and merged. Working as designed.
3. **No change — the operator's Stop hook `stop-tests-pass.sh`** asked the B
   main agent to run tests or record a skip at the end of its turn; the
   agent recorded a skip. That hook belongs to the operator's environment,
   not this plugin.
4. **False alarm, retracted:** a `ps | rg merge-when-green` check reported no
   merger process while PR #4 was open; `ps` truncates argv without `-ww`.
   `spawn.log` shows the merge happened.

## How the B session was driven

The Orca app was not running, so the interactive session ran in a detached
tmux pty (a real interactive `claude`, entrypoint `cli`), read with
`tmux capture-pane`:

```
claude --permission-mode auto --plugin-dir <worktree> \
  --settings '{"enabledPlugins":{"found-issues@altdoug-plugins":false}}' \
  "<prompt: run one found-issues log command, then follow the hook's instruction, edit nothing>"
```
